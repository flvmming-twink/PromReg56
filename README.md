# PromRegion56

Открытый промышленный атлас Оренбургской области: предприятия, территории, отрасли, показатели и первичные источники в одном статическом интерфейсе.

В интерфейсе есть интерактивная карта предприятий, обзорные графики, годовые показатели предприятий и территорий, фильтры и выгрузка реестра в CSV.

## Локальный запуск

Откройте папку через любой статический HTTP-сервер и перейдите на index.html. Сборка и установка пакетов не требуются.

## Данные

Базовый PostgreSQL-дамп находится в `database/industrial_city_db.sql`, а последующие изменения — в `database/migrations`. Текущая версия набора — `v5-2026-11-20`.

В базе сохранены 173 уникальных предприятия и 24 территории, а также добавлены:

- каталог из 61 показателя;
- 356 открытых источников;
- 591 проверенное значение с отдельной привязкой к источнику;
- 284 значения со статусом «требует сверки»;
- 140 детальных муниципальных показателей за 2021–2025 годы: 127 отчётных и 13 оценочных;
- очередь проверки 173 предприятий, включая 17 приоритетных карточек Новотроицка;
- идентификация 50 карточек Орска и Оренбурга, 7 предупреждений качества и 6 показателей с точным периодом наблюдения;
- журнал методологических проблем и сведения о выпусках набора данных.

Клиент использует `metric_values` и `metric_catalog`. Проверенные значения имеют приоритет перед унаследованными, но пропуски не интерполируются и не заменяются нулями.

После обновления дампа пересоберите клиентский файл:

~~~powershell
node scripts/build-data.mjs
~~~

Скрипт читает исходные `COPY`-блоки и расширения v2–v5, включая миграции городских карточек, применяет обновления реквизитов и статусов, затем формирует статические клиентские представления для карточек, графиков, источников и очередей исследования. Муниципальные оценки и неполные периоды показываются отдельно от отчётных годовых рядов. PostgreSQL в рантайме GitHub Pages не требуется.

Для обновления существующей PostgreSQL-базы последовательно применяются:

~~~powershell
psql -v ON_ERROR_STOP=1 $env:DATABASE_URL -f database/migrations/city_cards_2021_2025.sql
psql -v ON_ERROR_STOP=1 $env:DATABASE_URL -f database/migrations/fill_seven_city_gaps.sql
psql -v ON_ERROR_STOP=1 $env:DATABASE_URL -f database/migrations/remove_duplicate_metalex.sql
~~~

Карта использует локальную копию Leaflet 1.9.4 и стандартный слой OpenStreetMap с обязательной атрибуцией. Для отображения картографической подложки требуется подключение к интернету; остальные данные хранятся в репозитории.
