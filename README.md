# PromRegion56

Чистый каркас промышленного атласа Оренбургской области для последующего наполнения предприятиями и показателями.

В интерфейсе сохранены интерактивная карта, перечень территорий, отраслевые категории, фильтры, карточки и места для будущих графиков. Реестр предприятий и все показатели сейчас пусты.

## Локальный запуск

Откройте папку через любой статический HTTP-сервер и перейдите на index.html. Сборка и установка пакетов не требуются.

## Данные

Чистая PostgreSQL-схема находится в `database/industrial_city_db.sql`. Текущая версия — `skeleton-2026-11-21`.

В базе сохранены:

- 24 территории для навигации и будущей привязки объектов;
- 8 отраслевых категорий;
- пустые таблицы предприятий, показателей, проектов, источников и контроля качества.

Записи предприятий и показателей намеренно отсутствуют. Нули в интерфейсе означают пустой набор, а не статистические значения.

После обновления дампа пересоберите клиентский файл:

~~~powershell
node scripts/build-data.mjs
~~~

Скрипт читает `COPY`-блоки чистой схемы и формирует `data.js` для статического интерфейса. После наполнения SQL достаточно повторно запустить эту команду. PostgreSQL в рантайме GitHub Pages не требуется.

Для развёртывания чистой схемы в PostgreSQL выполните:

~~~powershell
psql -v ON_ERROR_STOP=1 $env:DATABASE_URL -f database/industrial_city_db.sql
~~~

Карта использует локальную копию Leaflet 1.9.4 и стандартный слой OpenStreetMap с обязательной атрибуцией. Для отображения картографической подложки требуется подключение к интернету; остальные данные хранятся в репозитории.
