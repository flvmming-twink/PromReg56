# PromRegion56

Промышленный атлас Новотроицка, Орска и Оренбурга с предприятиями, годовыми показателями и открытыми источниками.

В интерфейсе есть интерактивная карта, фильтры, карточки предприятий и территорий, графики за 2021–2025 годы и выгрузка реестра в CSV.

## Локальный запуск

Откройте папку через любой статический HTTP-сервер и перейдите на index.html. Сборка и установка пакетов не требуются.

## Данные

Основной PostgreSQL-дамп находится в `database/industrial_city_db.sql`. Текущая версия — `v7-2years-2026-11-22`.

В базе сохранены только три города:

- Новотроицк — 16 предприятий;
- Орск — 19 предприятий;
- Оренбург — 24 предприятия.

Итоговая витрина v7 содержит 59 предприятий и 761 ненулевое годовое наблюдение, объединённое в 187 рядов. Для каждого отдельного показателя предприятия сохранены только серии, содержащие как минимум два разных календарных года в периоде 2021–2025. `NULL` и отсутствующий год остаются пропуском и не заменяются нулём.

В выпуске v7 отмечены 185 проверенных и 576 требующих сверки точек. Из них 218 значений опубликованы источником с округлением до 0,1 млн рублей и показываются со знаком приблизительности. Для 15 предприятий доступна последняя подтверждённая среднесписочная численность; один год численности не создаёт отдельный график. Подробные ограничения и проверки приведены в [документации v7](docs/BFO_V7_README.md) и [контрольном списке](docs/BFO_V7_VALIDATION.md).

Контрольные CSV и сводка выпуска находятся в `database/v7`. Каноническая клиентская выборка хранится в `data_v7.json`, а её структурные проверки — в `tests/validate_v7.mjs`. Предыдущий аудит v6 сохранён в `database/bfo_v6`.

Статусы `legacy_pending`, `registry_linked_pending` и `registry_rounded` не означают независимую проверку. Они явно помечены в таблицах и подсказках. Муниципальные оценки отделены от отчётных значений. Выручку юридических лиц нельзя использовать как прямую оценку промышленного выпуска города.

После обновления дампа пересоберите клиентский файл:

~~~powershell
node scripts/build-data.mjs
~~~

Скрипт читает SQL, формирует базовую витрину и автоматически применяет каноническую выборку v7 через `scripts/apply_v7_dataset.mjs`. GitHub Pages не подключается к PostgreSQL напрямую; после изменения дампа или `data_v7.json` витрину необходимо собрать заново.

Проверить структуру канонической витрины можно командой:

~~~powershell
node tests/validate_v7.mjs
~~~

Для развёртывания на новой пустой PostgreSQL-базе выполните:

~~~powershell
psql -v ON_ERROR_STOP=1 $env:DATABASE_URL -f database/industrial_city_db.sql
~~~

Дамп намеренно остановится, если таблица `public.cities` уже существует. Для действующей базы с установленной v6 отдельно предоставлена миграция `database/promregion56_v7_UPDATE_AFTER_V6.sql`; сначала применяйте её к тестовой копии.

Карта использует локальную копию Leaflet 1.9.4 и стандартный слой OpenStreetMap с обязательной атрибуцией. Для отображения картографической подложки требуется подключение к интернету; остальные данные хранятся в репозитории.
