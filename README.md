# Комплексная ИС для консолидации данных предприятий Оренбургской области

Открытая демонстрация веб-интерфейса: https://flvmming-twink.github.io/kompleksnaya-is-orenburg/

## Размещение на GitHub Pages

1. Создайте публичный репозиторий `kompleksnaya-is-orenburg` в аккаунте `flvmming-twink`.
2. Загрузите **содержимое этой папки**, а не сам ZIP-файл, в корень ветки `main`.
3. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, **main**, **/(root)** и сохраните.
4. После успешного развёртывания откройте URL выше.

## Особенности демо

На GitHub Pages работает только статическая часть: HTML/CSS/JavaScript. Страница использует встроенные демонстрационные данные. Flask, PostgreSQL, вход администратора, запись и экспорт серверных отчётов не работают на GitHub Pages. Функции аналитики, зависящие от `/api/analytics`, переходят к предусмотренным в исходном коде демонстрационным данным. Исходный Flask-проект и конфигурация Render находятся в `backend/`; их нужно разворачивать на серверной платформе отдельно. Числовые показатели встроенного демо нельзя считать подтверждённой статистикой.

Не загружайте в публичный репозиторий реальные пароли, токены или персональные данные.
