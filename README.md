# PromRegion56

Промышленный атлас Новотроицка, Орска и Оренбурга с предприятиями, годовыми показателями и открытыми источниками.

В интерфейсе есть интерактивная карта, фильтры, карточки предприятий и территорий, графики за 2021–2025 годы и выгрузка реестра в CSV.

## Локальный запуск

Откройте папку через любой статический HTTP-сервер и перейдите на index.html. Сборка и установка пакетов не требуются.

## Данные

Основной PostgreSQL-дамп находится в `database/industrial_city_db.sql`. Текущая версия — `three-cities-2026-11-21`.

В базе сохранены только три города:

- Новотроицк — 15 предприятий;
- Орск — 19 предприятий;
- Оренбург — 5 предприятий.

Итоговый набор содержит 39 предприятий, 180 годовых строк, 374 значения показателей предприятий, 93 продуктовые позиции, 69 связей предприятий с источниками и 140 детальных муниципальных показателей. Для каждого показателя предприятия сохранены только серии, содержащие не менее трёх календарных лет. `NULL` остаётся пропуском и не заменяется нулём.

Статусы `source_linked_legacy` и `public_registry_summary` не означают независимую аудиторскую проверку. Муниципальные оценки отделены от отчётных значений. Выручку юридических лиц нельзя использовать как прямую оценку промышленного выпуска города.

После обновления дампа пересоберите клиентский файл:

~~~powershell
node scripts/build-data.mjs
~~~

Скрипт читает отфильтрованный SQL и формирует статическую витрину `data.js`. GitHub Pages не подключается к PostgreSQL напрямую; после изменения дампа витрину необходимо собрать заново.

Для развёртывания на новой пустой PostgreSQL-базе выполните:

~~~powershell
psql -v ON_ERROR_STOP=1 $env:DATABASE_URL -f database/industrial_city_db.sql
~~~

Дамп намеренно остановится, если таблица `public.cities` уже существует. Для обновления действующей БД безопаснее создать новую базу, проверить её и переключить подключение.

Карта использует локальную копию Leaflet 1.9.4 и стандартный слой OpenStreetMap с обязательной атрибуцией. Для отображения картографической подложки требуется подключение к интернету; остальные данные хранятся в репозитории.
