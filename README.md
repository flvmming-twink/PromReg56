# PromRegion56

Открытый промышленный атлас Оренбургской области: предприятия, территории, отрасли, показатели и первичные источники в одном статическом интерфейсе.

В интерфейсе есть интерактивная карта предприятий, обзорные графики, годовые показатели предприятий и территорий, фильтры и выгрузка реестра в CSV.

## Локальный запуск

Откройте папку через любой статический HTTP-сервер и перейдите на index.html. Сборка и установка пакетов не требуются.

## Данные

Исходный PostgreSQL-дамп находится в database/industrial_city_db.sql и взят из открытого репозитория [katebron-lang/PromRegion56](https://github.com/katebron-lang/PromRegion56).

После обновления дампа пересоберите клиентский файл:

~~~powershell
node scripts/build-data.mjs
~~~

Интерфейс показывает только значения, присутствующие в дампе. Отсутствующие сведения не заменяются демонстрационными данными.

Карта использует локальную копию Leaflet 1.9.4 и стандартный слой OpenStreetMap с обязательной атрибуцией. Для отображения картографической подложки требуется подключение к интернету; остальные данные хранятся в репозитории.
